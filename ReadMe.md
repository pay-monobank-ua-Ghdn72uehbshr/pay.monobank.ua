R# ElektroTransKvutok
Это демонстрационная статическая страница для показа макета билета в стиле Monobank.

## Что содержит
- страница билета с QR-кодом
- отображение номера, суммы и таймера
- лоадер во время загрузки
- демонстрационная информация о билете

## Примечание
Это демонстрационный проект для учебных и тестовых целей.
